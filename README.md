# NIST DTSA-II
NIST DTSA-II is "Power tools for X-ray Microanalysis."

NIST DTSA-II depends upon the EPQ library which is available [here.](https://github.com/NicholasWMRitchie/EPQ)

Installable versions of NIST DTSA-II are available [here](https://cstl.nist.gov/div837/837.02/epq/dtsa2/index.html)

Pre-release versions of NIST DTSA-II are available [here with Windows JRE](https://drive.google.com/file/d/17YAXRYkQ9vAQ509AwP5eZagdGfShX-dE/view?usp=drive_link) and [here w/o a JRE](https://drive.google.com/file/d/1O5ZhYX34ByxeuD6ocVbqp8xIljq9FEc0/view?usp=drive_link)

Documentation for DTSA-II is [here.](https://github.com/usnistgov/DTSA2_Documentation/blob/main/dtsa2home.md)
